# Operations
- **Daily 06:30:** health note (backup age, disk, failed units, containers, reboot needed, upgrades). Alerts are lines starting with `ALERT`.
- **Nightly:** encrypted backup; weekly restore check.
- **After a server reboot:** re-create the isolated container network rules, restart the agent panes, check the health note.
- **Change log:** every edit has a path, a backup and an undo line before the task ends.
- **Routine for a new session:** read the short core memory, the to-do list and the latest health note; then act.
